1 What is an Array?

An array is an ordered list of values. Each value is called an element and has a numeric position called an index. Indexes start at 0.

  • Can hold any type: numbers, strings, booleans, objects, even other arrays.
  • Can mix types (though usually you shouldn't).
  • Size is dynamic — it grows and shrinks automatically.
  • Arrays are objects under the hood: typeof [] === "object".
0"apple"
1"banana"
2"cherry"
3"date"

length = 4 · first index = 0 · last index = length − 1

2 Creating Arrays

The array literal [] is the preferred way. Other ways exist but are used in special cases.

Tip: Use const for arrays. You can still change the contents — you just can't reassign the variable.

4 Adding & Removing: push, pop, shift, unshift

Method What it does Returns
push(x) Add to the end new length
pop() Remove from the end removed element
unshift(x) Add to the start new length
shift() Remove from the start removed element

All four mutate (change) the original array.

Real-world use: push/pop = a stack (undo history). push/shift = a queue (waiting line).

5 slice vs splice

These two names are confusing — they do very different things.

slice(start, end)

Returns a copy of a portion. Does not change the original. end is excluded.

splice(start, deleteCount, ...items)

Changes the original: remove, insert or replace elements. Returns removed items.

6 Searching: indexOf, includes, find, findIndex

Rule of thumb: value you already know → includes/indexOf. Need to test a condition → find/findIndex.

7 Looping Over Arrays

Avoid for...in on arrays — it loops over keys (as strings) and can include unexpected properties.

8 The Big Three: map, filter, reduce

These are the most important array methods in modern JavaScript. None of them mutate the original array.

map — transform every element

Returns a new array of the same length.

filter — keep only what passes a test

Returns a new array with equal or fewer elements.

reduce — boil an array down to one value

reduce((accumulator, current) => newAccumulator, initialValue)

acc = 0
+ 10 →
acc = 10
+ 20 →
acc = 30
+ 30 →
acc = 60
Always give reduce an initial value. Without one, reduce on an empty array throws a TypeError.

9 some & every

Both return a boolean and stop as soon as the answer is known.

  • some → is at least one element passing the test?
  • every → do all elements pass the test?

10 sort & reverse

Big gotcha: sort() with no argument converts items to strings and sorts alphabetically. Numbers need a compare function!

Compare function: return negative → a first · positive → b first · 0 → keep order. Note: sort and reverse mutate, which is why we copy with [...nums] first.

13 Destructuring, Spread & Rest

Shallow copy warning: [...arr] and slice() copy only the first level. Nested objects/arrays are still shared references. Use structuredClone(arr) for a deep copy.

17 Practice Challenges

Try to solve each challenge in the editor first, then reveal the solution.

Challenge 1 · Square the odd numbers

From [1,2,3,4,5,6] return the squares of only the odd numbers.

Show solution 
const result = nums.filter(n => n % 2 !== 0).map(n => n ** 2);
console.log(result); // [1, 9, 25]

Challenge 2 · Average marks

Calculate the average of all student marks.

Show solution 
const avg = marks.reduce((a, b) => a + b, 0) / marks.length;
console.log(avg); // 78.6

Challenge 3 · Unique & sorted

Remove duplicates and sort ascending.

Show solution 
const result = [...new Set(data)].sort((a, b) => a - b);
console.log(result); // [1, 3, 5, 8, 9]

Challenge 4 · Longest word

Find the longest word in the array.

Show solution 
const longest = words.reduce((a, b) => (b.length > a.length ? b : a));
console.log(longest); // "javascript"

Challenge 5 · Flatten & total

Sum every number in a nested array.

Show solution 
const total = nested.flat(Infinity).reduce((a, b) => a + b, 0);
console.log(total); // 21
