Lecture 06 — Build a Portfolio Website

1. What We Will Build

Our portfolio will contain four pages:

  • Home
  • About
  • Projects
  • Contact

All pages will have the same navigation bar.

2. Project Folder Structure

```

portfolio/
│
├── index.html
├── about.html
├── projects.html
├── contact.html
│
└── style.css
```

We will use one external CSS file called style.css for all pages.

3. Why External CSS?

Instead of writing CSS separately on every HTML page, we create one CSS file and connect it to every page. 

```
```

This allows us to maintain the design from one place.

4. Navigation Bar

We will create a navigation bar using the <nav> element and anchor tags. 

```




```
<a href="index.html">Home</a>

<a href="about.html">About</a>

<a href="projects.html">Projects</a>

<a href="contact.html">Contact</a>
```
```

The href attribute tells the browser which HTML page to open.

5. HTML Routing

In this project, we are using simple HTML page-to-page navigation.

For example:

```

Home → index.html

About → about.html

Projects → projects.html

Contact → contact.html
```

When the user clicks a link, the browser opens the corresponding HTML file.

10. External CSS — style.css

Now create a file called style.css. 

```

/* General Styling */

body {
font-family: Arial, sans-serif;
margin: 0;
background-color: #f4f4f4;
color: #222;
}

/* Navigation Bar */

nav {
background-color: #222;
padding: 20px;
}

nav h2 {
color: white;
display: inline;
}

nav div {
float: right;
}

nav a {
color: white;
text-decoration: none;
margin-left: 20px;
}

/* Navigation Hover */

nav a:hover {
color: orange;
}

/* Main Content */

main {
padding: 50px;
}

/* Sections */

section {
background-color: white;
padding: 40px;
}

/* Headings */

h1 {
color: #1f4e79;
font-size: 40px;
}

h2 {
color: #333;
}

/* Paragraphs */

p {
font-size: 18px;
line-height: 1.6;
}

/* Links */

a {
color: #1f4e79;
}

/* Project Boxes */

section div {
background-color: #eeeeee;
padding: 20px;
margin-bottom: 20px;
}
```

11. Understanding the CSS

body

```

body {
font-family: Arial, sans-serif;
margin: 0;
background-color: #f4f4f4;
}
```

This styles the complete webpage.

nav

```

nav {
background-color: #222;
padding: 20px;
}
```

This creates the dark navigation bar.

nav a

```

nav a {
color: white;
text-decoration: none;
margin-left: 20px;
}
```

This styles the navigation links.

nav a:hover

```

nav a:hover {
color: orange;
}
```

The :hover pseudo-class applies the style when the mouse pointer is over the link.

14. Student Task

Students should create their own portfolio website by replacing the example content with their own information.

Requirements

  1. Create all four HTML pages.
  2. Create one external CSS file.
  3. Add the same navbar to every page.
  4. Add Home, About, Projects and Contact links.
  5. Add your own name.
  6. Add your own introduction.
  7. Add at least three projects.
  8. Add your skills.
  9. Add your contact information.
  10. Style the website using CSS.
  11. Test every navigation link.
