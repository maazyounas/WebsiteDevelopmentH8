Lecture 05 — CSS Basics

1. What is CSS?

CSS stands for Cascading Style Sheets.

CSS is used to style and design HTML elements. It controls how a webpage looks.

HTML vs CSS

  • HTML → Structure of the webpage
  • CSS → Design and appearance of the webpage
  • JavaScript → Behavior and functionality

For example:

```

HTML → Creates a heading
CSS  → Changes its color and size
JavaScript → Makes it interactive
```

2. Why Do We Use CSS?

CSS allows us to:

  • Change text color
  • Change background color
  • Change font size
  • Change font weight
  • Align text
  • Add spacing
  • Add borders
  • Design buttons
  • Create layouts
  • Make websites responsive

3. CSS Syntax

The basic CSS syntax is:

```

selector {
property: value;
}
```

Example

```

p {
color: blue;
}
```

Here:

  • p → Selector
  • color → Property
  • blue → Value

4. CSS Comments

Comments are ignored by the browser.

```

/* This is a CSS comment */

p {
color: red;
}
```

5. Element Selector

The element selector selects HTML elements by their tag name. 

```

p {
color: blue;
}

h1 {
color: red;
}

button {
background-color: black;
}
```

Example

```


Hello Students


Welcome to CSS
```

The h1 selector selects all h1 elements. The p selector selects all paragraph elements.

6. Class Selector

A class selector is used when we want to style one or more elements using the same class.

A class selector starts with a dot (.). 

```

.title {
color: blue;
}
```

HTML

```


My Website



Welcome to my website
```

Both elements will receive the same CSS because they have the class title.

This paragraph uses a class selector.

7. ID Selector

An ID selector is used to target a specific HTML element.

An ID selector starts with a #. 

```

#heading {
color: green;
}
```

HTML

```


Welcome
```

The ID value should normally be unique on a page.

8. Class vs ID

```

Class → .
ID    → #

Example:

.box {
color: blue;
}

#main-heading {
color: red;
}
```
  • Class → Can be reused on multiple elements.
  • ID → Normally used for one unique element.

9. Inline CSS

Inline CSS is written directly inside the HTML element using the style attribute. 

```



Hello World
```

This paragraph is styled using inline CSS.

Inline CSS is useful for quick testing, but it is generally not recommended for large projects.

10. Internal CSS

Internal CSS is written inside the <style> tag in the HTML document's <head>. 

```



```
<style>

    p {
        color: blue;
    }

</style>
```
```

Internal CSS is useful when styling a single HTML page.

11. External CSS

External CSS is written in a separate .css file.

style.css

```

p {
color: blue;
}

h1 {
color: red;
}
```

index.html

```



```
<link rel="stylesheet" href="style.css">
```
```

External CSS is the most commonly used approach for real websites because it keeps HTML and CSS separate.

12. CSS Types Comparison

Type Where? Example
Inline Inside HTML element style="color:red"
Internal Inside <style> style tag
External Separate .css file style.css

CSS Heading Example

15. Grouping Selectors

We can apply the same CSS to multiple elements by separating selectors with commas. 

```

h1, h2, p {
color: blue;
}
```

16. Universal Selector

The universal selector * selects all HTML elements. 

```

* {
  margin: 0;
  padding: 0;
  }
```

This is commonly used to reset default browser spacing.

18. CSS Units

Some common CSS units are:

  • px → Pixels
  • % → Percentage
  • em → Relative to parent font size
  • rem → Relative to root font size
  • vh → Viewport height
  • vw → Viewport width

For now, students should mainly practice with px.

```

h1 {
font-size: 40px;
}

div {
width: 50%;
}
```

19. CSS Cascade — Basic Idea

CSS is called Cascading Style Sheets because multiple CSS rules can affect the same element.

When rules conflict, the browser uses CSS rules such as specificity and source order to determine which style applies.

For now, remember: 

```

Inline CSS
↓
ID selector
↓
Class selector
↓
Element selector
```

This is only a beginner introduction to specificity. We will study it in more detail later.
