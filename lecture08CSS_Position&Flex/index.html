CSS Position & Flexbox

Today's lecture covers CSS positioning and Flexbox properties.

Part 1 — CSS Position

CSS position controls how an element is positioned on a webpage.

1. position: static;

Static

Static is the default position of an element.

2. position: relative;

Relative

The element stays in its normal position but can be moved using top, right, bottom or left.

3. position: absolute;

Absolute

The absolute element is positioned relative to its nearest positioned parent.

4. position: fixed;

Scroll the page and notice the small button in the bottom-right corner.

5. position: sticky;

I am Sticky

Scroll the page to see how the sticky element behaves.

Sticky starts like a normal element and sticks to a position when the specified scroll point is reached.

Position Properties

The following properties are used to move positioned elements.

  • top
  • right
  • bottom
  • left
  • z-index
