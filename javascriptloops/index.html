01

Why do we need loops?

Definition: A loop is a control-flow structure that repeats a block of code. Depending on the loop, repetition continues while a condition is true or until a stopping condition is reached.

Suppose we want to print the numbers 1 to 5. Without a loop, we repeat the same instruction many times: 

console.log(1);
console.log(2);
console.log(3);
console.log(4);
console.log(5);

A loop expresses the repeated task once:

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

Common uses

  • Counting and printing sequences
  • Calculating totals and factorials
  • Reading array items
  • Generating tables and patterns
  • Repeating work until a condition changes

Key vocabulary

  • Iteration: one pass through a loop
  • Counter: a variable tracking progress
  • Condition: an expression evaluated as true or false
  • Loop body: the code that repeats
02

Understand the parts of a loop

A common for loop has three expressions inside its parentheses, separated by semicolons. 

for (initialization; condition; update) {
  // loop body
}
  1. Initialization: runs once at the beginning, often to set a counter.
  2. Condition: checked before each iteration. If it is false, the loop ends.
  3. Body: runs when the condition is true.
  4. Update: changes the counter after the body runs.
Initialize→Check condition→ true →Run body→Update False condition → exit the loop

i++ increments i by one and is shorthand for i = i + 1. Similarly, i-- subtracts one. An update can also be i += 2 to increase by two.

03

The for loop

Definition: Use a for loop when the repetition follows a counter or when the number of iterations is reasonably predictable.

Syntax and example

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

First, i starts at 1. The condition i <= 5 is checked. The body prints the current value, then i++ increases it. When i becomes 6, the condition is false and the loop stops.

The step must move toward the end value. A step of 0 is not allowed.

Common variations

// Count down
for (let i = 5; i >= 1; i--) {
  console.log(i);
}

// Count by twos
for (let i = 2; i <= 10; i += 2) {
  console.log(i); // 2, 4, 6, 8, 10
}

// The three expressions can be omitted,
// but you must still provide the semicolons.
for (;;) {
  // This has no natural stopping condition.
  break; // example only: exit immediately
}

Scope note: A counter declared with let in the loop header is limited to that loop block. Prefer let for counters that change; use const for values that are not reassigned.

04

The while loop

Definition: A while loop repeats its body as long as its condition is true. The condition is checked before the body on every iteration, so the body might run zero times. 

let i = 1;

while (i <= 5) {
  console.log(i);
  i++;
}

Use while when repetition depends on a condition and you may not know the number of iterations in advance. For example, keep processing while items remain.

Important: The counter update is inside the body here. If you forget i++, then i stays at 1 and the condition stays true forever.

05

The do...while loop

Definition: A do...while loop runs its body first and checks the condition afterward. Therefore, its body always executes at least once, even when the condition is initially false. 

let i = 1;

do {
  console.log(i);
  i++;
} while (i <= 5);

Notice the semicolon after the closing while (...).

See why it runs at least once

let number = 10;

do {
  console.log(number);
} while (number < 5);

06

Compare the three main loops

Feature for while do...while
Condition check Before each iteration Before each iteration After each iteration
May run zero times? Yes Yes No
Common use Counter-based repetition Condition-based repetition Must run at least once
Update location Usually in loop header Usually in body Usually in body

These are guidelines, not strict rules. Many tasks can be written with more than one loop type.

07

Nested loops

Definition: A nested loop is a loop placed inside another loop. For each iteration of the outer loop, the inner loop runs through its own iterations. 

for (let row = 1; row <= 3; row++) {
  for (let col = 1; col <= 2; col++) {
    console.log("row:", row, "column:", col);
  }
}

The inner loop runs twice for every outer-loop row, so the body runs 3 × 2 = 6 times. Use distinct counter names such as row and col to make the code easier to understand.

Star patterns

for (let row = 1; row <= 4; row++) {
  let stars = "";

  for (let col = 1; col <= row; col++) {
    stars += "* ";
  }

  console.log(stars);
}
*
* *
* * *
* * * *

The outer loop controls the number of rows. The inner loop controls how many stars appear in each row. Nested loops are useful for grids, tables, patterns, and two-dimensional data.

08

Controlling loops: break and continue

break — exit the loop

break immediately exits the nearest enclosing loop or switch statement. Code after that loop can then continue. 

for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break;
  }
  console.log(i);
}
// Output: 1, 2, 3, 4

continue — skip this iteration

continue skips the rest of the current iteration and proceeds to the next one. In a for loop, the update expression still runs; in a while loop, make sure your code does not accidentally skip a necessary counter update. 

for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    continue;
  }
  console.log(i);
}
// Output: 1, 2, 4, 5
Run a demo to compare the output.

Nested loop detail: A plain break exits only the nearest loop, not every loop around it. Labels can control outer loops too, but beginners should usually prefer clear functions or conditions over labeled breaks.

09

Other loop patterns in JavaScript

for...of — iterate over values

Use for...of to visit values in an iterable, such as an array or string. 

const fruits = ["Apple", "Mango", "Orange"];

for (const fruit of fruits) {
  console.log(fruit);
}

for...in — iterate over enumerable property keys

for...in visits enumerable string keys of an object. It can also visit inherited enumerable properties. For arrays, use for...of when you want values in order; for...in gives keys, not array values. 

const student = { name: "Ali", age: 20 };

for (const key in student) {
  console.log(key, student[key]);
}

Array methods as alternatives

JavaScript also provides methods that often make array operations clearer: 

const numbers = [1, 2, 3, 4];

numbers.forEach(number => console.log(number));

const doubled = numbers.map(number => number * 2);
const evens = numbers.filter(number => number % 2 === 0);

forEach, map, and filter are array methods, not loop statements. Choose the approach that best communicates the task. A regular loop is useful when you need break, continue, or more control over iteration.

10

Infinite loops and common mistakes

Definition: An infinite loop is a loop that does not reach its intended stopping condition. It may freeze a page or make the browser unresponsive.

Bug: the counter never changes

let i = 1;
while (i <= 5) {
  console.log(i);
  // Missing i++: i remains 1
}

Fix: update the counter

let i = 1;
while (i <= 5) {
  console.log(i);
  i++;
}
Do not run an intentional infinite loop in the browser to test it. Use a safe, limited simulation instead.

Checklist to prevent loop bugs

  • Is the initial value correct?
  • Can the condition eventually become false?
  • Does the counter move toward the stopping point?
  • Are you using <= or < intentionally?
  • Could a continue skip the counter update in a while loop?
  • Have you tested with a small input?
11

Loop tracing: follow each iteration

Definition: Loop tracing means recording the values of variables and the output as the loop executes step by step. 

let sum = 0;

for (let i = 1; i <= 3; i++) {
  sum = sum + i;
}

console.log(sum); // 6
Iteration i Old sum New sum
1 1 0 1
2 2 1 3
3 3 3 6

After iteration 3, i increases to 4. The condition i <= 3 is false, so the loop ends. The final value of sum is 6.

12

Practice exercises

Try solving each exercise yourself before revealing the suggested solution. Use the interactive tools to test your understanding.

1. Print numbers from 1 to 100 
for (let i = 1; i <= 100; i++) {
  console.log(i);
}
2. Display the multiplication table of a number 
const number = 7;

for (let i = 1; i <= 10; i++) {
  console.log(`${number} x ${i} = ${number * i}`);
}
3. Calculate the sum from 1 to n 
const n = 5;
let sum = 0;

for (let i = 1; i <= n; i++) {
  sum += i;
}

console.log(sum); // 15
4. Calculate a factorial 
const n = 5;
let factorial = 1;

for (let i = 1; i <= n; i++) {
  factorial *= i;
}

console.log(factorial); // 120

Factorial of 0 is 1, so initializing the result to 1 handles that case.

5. Print a right-triangle star pattern 
for (let row = 1; row <= 5; row++) {
  let line = "";
  for (let col = 1; col <= row; col++) {
    line += "* ";
  }
  console.log(line);
}
6. Find even and odd numbers in a range 
for (let i = 1; i <= 20; i++) {
  if (i % 2 === 0) {
    console.log(i, "is even");
  } else {
    console.log(i, "is odd");
  }
}

The remainder operator % gives the remainder after division. A number divisible by 2 has remainder 0.

7. Print numbers backward from 10 to 1 
for (let i = 10; i >= 1; i--) {
  console.log(i);
}
8. Use continue to skip multiples of 3 
for (let i = 1; i <= 20; i++) {
  if (i % 3 === 0) continue;
  console.log(i);
}

Lesson summary

  • for is often ideal for counter-based repetition.
  • while checks a condition before running the body.
  • do...while runs the body before checking the condition.
  • Nested loops put one loop inside another.
  • break exits the nearest loop; continue skips to the next iteration.
  • for...of iterates values; for...in iterates enumerable property keys.
  • Trace the counter and condition to understand the exact execution flow.
