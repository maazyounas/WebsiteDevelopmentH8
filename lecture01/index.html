Web Development - Lecture 01

Introduction to Web Development

1. What is Web Development?

Web Development is the process of creating, building, and maintaining websites and web applications that run on the internet or a local network.

Web developers use different technologies to create websites and web applications. The three main technologies used in frontend development are:

  • HTML - Structure of a webpage
  • CSS - Design and appearance of a webpage
  • JavaScript - Behavior and functionality of a webpage

2. Why Do We Need to Learn Web Development?

Websites and web applications are an important part of modern life. Businesses, educational institutes, banks, hospitals, governments, and many other organizations use web technologies.

Some reasons to learn Web Development:

  • Build your own websites
  • Create web applications
  • Build business websites
  • Create online stores
  • Build portfolio websites
  • Create educational platforms
  • Work as a web developer
  • Work as a freelancer
  • Build your own startup or online business

3. What is a Website?

A website is a collection of web pages that are connected to each other and can be accessed through the internet using a web browser.

A website usually contains information such as text, images, videos, links, and other content.

Examples:

  • Company website
  • Portfolio website
  • News website
  • Blog website
  • Educational website

Example:

A university website may contain:

  • Home page
  • About page
  • Departments page
  • Admissions page
  • Contact page

4. What is a Web Application?

A web application is a software application that runs inside a web browser and allows users to interact with data and perform tasks.

Examples:

  • Gmail
  • Google Docs
  • Online Banking
  • Facebook
  • Learning Management Systems
  • Online Shopping Systems

Website vs Web Application

Website Web Application
Mainly provides information Allows users to perform tasks
Usually less interactive Usually highly interactive
Example: Company Website Example: Online Banking

5. What is a Web Browser?

A web browser is software that allows us to access and view websites and web applications on the internet.

Examples of Web Browsers:

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari
  • Opera

6. What is the Internet?

The Internet is a global network that connects millions of computers, servers, phones, and other devices around the world.

It allows devices to communicate and exchange information with each other.

7. What is a Server?

A server is a computer or system that provides resources, data, or services to other computers called clients.

When you visit a website, your browser sends a request to a server. The server processes the request and sends the required information back to your browser.

Simple Example:

Think of a server like a restaurant kitchen.

  • Customer = User
  • Waiter = Internet/Request
  • Kitchen = Server
  • Food = Requested webpage/data

8. What is a Client?

A client is a device or application that requests information or services from a server.

When you open a website using Google Chrome, your browser acts as a client.

Examples of Clients:

  • Web Browser
  • Mobile Application
  • Desktop Application
  • Another Server

9. Client-Server Model

Websites and web applications commonly work using the client-server model.

  1. User opens a browser.
  2. User enters a website address.
  3. Browser sends a request to the server.
  4. Server receives the request.
  5. Server processes the request.
  6. Server sends a response.
  7. Browser displays the response to the user.

Client → Request → Server → Response → Client

10. What is Web Hosting?

Web hosting is a service that stores your website files on a server and makes your website accessible through the internet.

Without hosting, other people generally cannot access your website through a public internet address.

Website files can include:

  • HTML files
  • CSS files
  • JavaScript files
  • Images
  • Videos
  • Other resources

11. What is a Domain Name?

A domain name is the human-readable address used to access a website.

Examples:

  • google.com
  • wikipedia.org
  • github.com

Instead of remembering a numerical IP address, users can use an easy-to-remember domain name.

12. What is an IP Address?

An IP address is a numerical address used to identify a device or server on a network.

Example:

192.168.1.1

Domain names make it easier for humans to access websites, while computers use IP addresses for network communication.

13. What is DNS?

DNS stands for Domain Name System.

DNS converts domain names into IP addresses so that computers can locate the correct server.

Simple Example:

When you type:

example.com

DNS helps find the IP address of the server where that website is hosted.

14. What is a URL?

URL stands for Uniform Resource Locator.

A URL is the complete address used to locate a resource on the web.

Example:

https://www.example.com/about

A URL can contain:

  • Protocol
  • Domain
  • Path
  • Query parameters

15. What are HTTP and HTTPS?

HTTP

HTTP stands for HyperText Transfer Protocol. It is a protocol used for communication between clients and servers.

HTTPS

HTTPS stands for HyperText Transfer Protocol Secure. It uses encryption to help protect data exchanged between the browser and the server.

Most modern websites use HTTPS.

16. How Does a Website Work?

Let's understand what happens when you open a website.

  1. You open a web browser.
  2. You enter a website address such as example.com.
  3. The browser needs to find the server associated with that domain.
  4. DNS helps resolve the domain name to an IP address.
  5. The browser sends a request to the server.
  6. The server receives and processes the request.
  7. The server sends a response back to the browser.
  8. The browser receives files such as HTML, CSS, and JavaScript.
  9. The browser processes those files.
  10. The webpage is displayed to the user.

User → Browser → DNS → Server → Response → Browser → Webpage

17. What is Frontend Development?

Frontend development is the development of the part of a website or web application that users can see and interact with.

Main Frontend Technologies:

  • HTML
  • CSS
  • JavaScript

Popular Frontend Frameworks and Libraries:

  • React
  • Angular
  • Vue

18. What is Backend Development?

Backend development deals with the server-side logic of a website or web application.

The backend can handle things such as:

  • User authentication
  • Business logic
  • Database operations
  • API requests
  • Data processing

Popular Backend Technologies:

  • Node.js
  • Python
  • Java
  • PHP
  • C# / .NET

19. What is a Database?

A database is a system used to store, organize, and manage data.

Examples of data stored in a database:

  • User accounts
  • Passwords
  • Products
  • Orders
  • Student records
  • Messages

Popular Databases:

  • MySQL
  • PostgreSQL
  • MongoDB
  • Microsoft SQL Server
  • Oracle Database

20. What is Full-Stack Development?

Full-stack development involves working with both frontend and backend parts of a web application.

A full-stack developer may work with:

  • Frontend
  • Backend
  • Database
  • APIs
  • Authentication
  • Deployment

Simple Example

  • HTML = Skeleton
  • CSS = Clothes / Appearance
  • JavaScript = Actions / Behavior

22. Static vs Dynamic Websites

Static Website

A static website mainly contains fixed content. The content usually changes when a developer manually changes the website files.

Examples:

  • Portfolio website
  • Simple business website
  • Landing page

Dynamic Website

A dynamic website can generate or update content based on users, databases, requests, or other data.

Examples:

  • Facebook
  • Online Banking
  • Learning Management System
  • E-commerce website

23. What is an API?

API stands for Application Programming Interface.

An API allows different software applications or systems to communicate with each other.

Example:

A weather application can request weather data from a weather API.

Weather App → API → Weather Server → API → Weather App

24. What is Deployment?

Deployment is the process of making a website or web application available for users to access.

For example, a developer may build a website on their computer and then deploy it to a hosting server so people can access it through the internet.

25. What is GitHub?

GitHub is a platform used to store, manage, share, and collaborate on software projects using Git.

Developers use GitHub to:

  • Store source code
  • Track changes
  • Collaborate with other developers
  • Share projects
  • Manage software versions
  • Build portfolios

26. What is Git?

Git is a version control system used to track changes in files and source code.

Git allows developers to save different versions of their projects and work safely with other developers.

27. Web Development Learning Roadmap

Step 1 - HTML

Learn how to create the structure of webpages.

Step 2 - CSS

Learn how to design and style webpages.

Step 3 - JavaScript

Learn programming and make webpages interactive.

Step 4 - Git & GitHub

Learn version control and how to manage projects.

Step 5 - Frontend Framework

Learn a framework or library such as React.

Step 6 - Backend

Learn server-side development and APIs.

Step 7 - Database

Learn how to store and manage application data.

Step 8 - Full-Stack Projects

Combine frontend, backend, databases, APIs, and deployment to build complete web applications.

Server

Client

Hosting
A service that stores website files and makes them accessible online.

Domain
A human-readable address used to access a website.

DNS
System that helps translate domain names into IP addresses.

Frontend
The part of a web application users see and interact with.

Backend
