JAVASCRIPT BASICS

Conditional Statements

Teach JavaScript how to make decisions based on conditions.

What are conditional statements?

Conditional statements let a program choose which code to run depending on whether a condition is true or false.

const temperature = 32;

if (temperature > 30) {
  console.log("It is a hot day.");
}

Remember: A condition is usually an expression that evaluates to a truthy or falsy value. Use curly braces { } to clearly mark the code inside each branch.

1. if

Runs a block only when its condition is true.

const age = 20;

if (age >= 18) {
  console.log("You can vote.");
}

If the condition is false, the block is skipped.

2. if...else

Chooses between two paths: one for true and one for false.

const age = 16;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

Exactly one of these two blocks runs.

3. else if

Checks multiple conditions in order. The first true branch runs.

const marks = 76;

if (marks >= 90) {
  console.log("Grade A");
} else if (marks >= 70) {
  console.log("Grade B");
} else if (marks >= 50) {
  console.log("Grade C");
} else {
  console.log("Needs improvement");
}

Order matters. Check higher grade boundaries first so a student with 95 marks receives Grade A.

4. Nested conditions

An if statement inside another if statement is called a nested condition.

const age = 22;
const hasID = true;

if (age >= 18) {
  if (hasID) {
    console.log("Entry allowed");
  } else {
    console.log("Please show ID");
  }
} else {
  console.log("Too young");
}

Use nesting when a second decision should be checked only after the first condition passes. Avoid too many nested levels.

5. switch

Matches one expression against several possible values. Use break to stop a case from falling through to the next one.

const day = "Monday";

switch (day) {
  case "Monday":
    console.log("Start of the week");
    break;
  case "Friday":
    console.log("Almost the weekend");
    break;
  default:
    console.log("Another day");
}

default runs if no case matches. switch uses strict matching, so value and type must match.

6. Truthy and falsy values

JavaScript can use non-Boolean values in conditions. These are converted to true or false in a Boolean context.

Falsy values:

false
0
-0
0n
""
null
undefined
NaN

Most other values are truthy, including "0", "false", [], and {}.

const username = "";

if (username) {
  console.log("Name entered");
} else {
  console.log("Name is missing");
}

7. Logical conditions

Combine or reverse conditions using logical operators.

  • && AND: both conditions must be truthy.
  • || OR: at least one condition must be truthy.
  • ! NOT: reverses a value's truthiness.
const age = 21;
const hasTicket = true;

if (age >= 18 && hasTicket) {
  console.log("You may enter");
}

if (age < 13 || age > 65) {
  console.log("Special price");
}

if (!hasTicket) {
  console.log("Buy a ticket first");
}

8. Ternary operator review

A concise way to choose one of two expressions. It is useful for simple decisions.

const age = 19;

const message = age >= 18
  ? "Adult"
  : "Minor";

console.log(message); // Adult

Pattern: condition ? valueIfTrue : valueIfFalse. Use regular if...else when the logic has multiple steps or becomes hard to read.

Practice questions

  1. What is the difference between if and if...else?
  2. Why should grade conditions usually check the highest marks first?
  3. What does if ("false") do, and why?
  4. What is the difference between && and ||?
  5. When is a switch statement useful?
  6. Rewrite age >= 18 ? "Adult" : "Minor" using if...else.
Show answers
  1. if runs code only if true; if...else provides a second path when false.
  2. Because the first matching branch runs; checking lower thresholds first can incorrectly assign a lower grade.
  3. The condition is truthy because a non-empty string is truthy, even if its text is "false".
  4. && needs both sides truthy; || needs at least one side truthy.
  5. When one expression is compared against several specific values, such as a day name or menu option.
  6. if (age >= 18) { result = "Adult"; } else { result = "Minor"; }
