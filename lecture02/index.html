Web Development - Lecture 02

Frontend Development & Introduction to HTML

1. What is Frontend Development?

Frontend development is the development of the part of a website or web application that users can see and interact with.

Everything that appears inside the browser, such as text, buttons, images, forms, menus, and layouts, is part of the frontend.

Example

When you open a website and see a navigation bar, heading, images, buttons, cards, and forms, these are frontend elements.

2. Main Frontend Technologies

The three fundamental technologies used in frontend development are:

Technology Purpose
HTML Creates the structure of a webpage
CSS Styles and designs the webpage
JavaScript Adds functionality and interactivity

Easy Way to Remember

  • HTML = Structure
  • CSS = Design
  • JavaScript = Behavior

3. What is HTML?

HTML stands for HyperText Markup Language.

HTML is the standard markup language used to create the structure of webpages.

HTML tells the browser what content should appear on a webpage, such as headings, paragraphs, images, links, lists, tables, and forms.

4. Is HTML a Programming Language?

No. HTML is a markup language, not a programming language.

HTML is used to structure content. It does not provide programming concepts such as conditions, loops, or functions.

JavaScript is a programming language that can be used to add programming logic and interactivity to webpages.

5. What is Visual Studio Code?

Visual Studio Code, commonly called VS Code, is a source-code editor developed by Microsoft.

We will use VS Code to write and manage our HTML, CSS, and JavaScript code.

6. Setting Up VS Code

Before starting development, we install Visual Studio Code and prepare our development environment.

Basic Setup

  1. Download and install Visual Studio Code.
  2. Open Visual Studio Code.
  3. Create a folder for your web development course.
  4. Open that folder in VS Code.
  5. Create a new HTML file.
  6. Save the file as index.html.

7. Useful VS Code Extensions

Extensions add additional functionality to Visual Studio Code and can make development easier.

Common Extensions for Web Development

  • Live Server
    Allows us to open our webpage in a browser and automatically reload it when we save changes.

  • Prettier - Code Formatter
    Automatically formats code and keeps its structure clean.

  • Auto Rename Tag
    Automatically changes the closing tag when an HTML tag is renamed.

  • Auto Close Tag
    Automatically adds closing HTML tags.

Extensions are helpful tools, but learning HTML itself is more important than depending on extensions.

10. What is DOCTYPE?

<!DOCTYPE html> tells the browser that the document uses HTML5.

It should normally be written at the beginning of an HTML document.

11. What is an HTML Tag?

HTML uses tags to define different types of content.

Example: 

```


Hello World
```

Here:

  • <h1> is the opening tag.
  • Hello World is the content.
  • </h1> is the closing tag.

12. What is an HTML Element?

An HTML element generally consists of an opening tag, content, and a closing tag. 

```


This is a paragraph.
```

The complete structure above is an HTML element.

13. What is the <head> Element?

The <head> element contains information about the webpage that is generally not displayed as normal page content.

It can contain:

  • Page title
  • Character encoding
  • Viewport information
  • CSS files
  • Other metadata

14. What is the <body> Element?

The <body> element contains the content that is displayed on the webpage.

Examples include:

  • Headings
  • Paragraphs
  • Images
  • Links
  • Lists
  • Tables
  • Forms
  • Buttons

20. How to Run an HTML File

  1. Open your HTML file in VS Code.
  2. Save the file.
  3. Right-click the HTML file.
  4. Select Open with Live Server.
  5. Your webpage will open in the browser.

Whenever you make changes, save the file and Live Server can refresh the webpage automatically.

21. How HTML Reaches the Browser

When we create an HTML file, the browser reads the HTML code and converts it into the webpage that we see on the screen.

The browser does not simply display the HTML code as text. Instead, it interprets the HTML elements and builds the webpage structure.

HTML Code → Browser → Webpage
