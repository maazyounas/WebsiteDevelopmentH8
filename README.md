# 🌐 Website Development Course

Welcome to the **Website Development Course** repository.

This repository contains lecture notes, examples, exercises, and practical projects created while learning **Web Development from the basics**.

The course is designed for beginners and gradually introduces students to **HTML, CSS, Git, GitHub, and practical website development**.

---

## 📚 Course Content

### Lecture 01 — Introduction to Web Development

Introduction to the world of web development.

Topics covered:

* What is Web Development?
* Website vs Web Application
* Internet and Web
* Browser
* Client and Server
* Client-Server Model
* Web Hosting
* Domain Names
* IP Address
* DNS
* URL
* HTTP and HTTPS
* Frontend
* Backend
* Database
* Full-Stack Development
* APIs
* Git and GitHub introduction
* Web Development Roadmap

### Lecture 02 — Introduction to HTML

Learning the fundamentals of HTML and setting up the development environment.

Topics covered:

* HTML document structure

* `<html>`

* `<body>`
* `<title>`

* Paragraphs
* Comments

* Live Server

### Lecture 04 — Git & GitHub

Introduction to version control and using GitHub for managing web development projects.

Topics covered:

* Git vs GitHub

* Git configuration

* Git email configuration
* Connecting GitHub with VS Code
* Creating repositories
* Local repositories
* Remote repositories
* `git init`
* `git status`
* `git add`
* `git commit`
* `git log`
* `git branch`
* `git switch`
* `git remote`
* `git push`
* `git pull`
* `git fetch`
* `git clone`
* `git diff`

```bash
git status

```

## 🚀 How to Use This Repository

Students can clone the repository using:

```bash
git clone https://github.com/maazyounas/WebsiteDevelopmentH8.git
```

Then open the project in VS Code:

```bash
cd WebsiteDevelopmentH8
```

Open the folder in **Visual Studio Code** and explore each lecture in order.

## 🎯 Learning Approach

The course follows a practical learning approach:

```text
Learn
  ↓
Understand
  ↓
Practice
  ↓
Build
  ↓
Push to GitHub
```

Each lecture introduces concepts and provides examples that students can practice themselves.
