JavaScript Operators

Learn what operators do, read examples, and try the interactive playground.

What is an operator?

An operator is a symbol or keyword that performs an action on values. For example, + adds numbers or joins strings, while === checks whether two values are equal without converting their types.

Teaching tip: Ask students to predict each result before revealing it in the browser console or the examples below.

1. Logical operators

Combine or reverse Boolean conditions.

  • && (AND): true only when both sides are truthy.
  • || (OR): true when at least one side is truthy.
  • ! (NOT): converts a value to Boolean and reverses it. 
const age = 20;
const hasID = true;

age >= 18 && hasID; // true
age < 18 || hasID; // true
!hasID;             // false

These operators can return one of their operands, not always a Boolean. They also short-circuit: the right side may not run if the result is already known.

2. Increment and decrement

++ adds 1; -- subtracts 1.

let score = 4;
score++; // score is now 5
score--; // score is now 4

count++ (postfix) gives the old value in an expression; ++count (prefix) gives the updated value. 

let count = 5;
console.log(count++); // 5, then count becomes 6
console.log(++count); // 7

They are commonly used with numeric variables. The variable must be assignable, such as a let variable.

3. String concatenation & template literals

Concatenation joins strings. Template literals use backticks and ${...} to insert values. 

const first = "Maaz";
const last = "Younas";

const fullName = first + " " + last;
const message = `Hello, ${fullName}!`;

console.log(fullName); // Maaz Younas
console.log(message);  // Hello, Maaz Younas!

If one operand of + is a string, JavaScript often converts the other value to a string. Use template literals for readable messages.

4. Operator precedence

Precedence determines which operation is evaluated first. Parentheses can make the order clear. 

const result1 = 2 + 3 * 4;   // 14
const result2 = (2 + 3) * 4; // 20
const result3 = 10 - 4 / 2;  // 8

Multiplication and division happen before addition and subtraction. When in doubt, use parentheses instead of relying on memory.

5. Ternary operator

A compact way to choose one of two expressions based on a condition. 

const age = 17;
const access = age >= 18 ? "Allowed" : "Not allowed";

console.log(access); // Not allowed

Read it as: condition ? value if true : value if false. For complicated decisions, use if...else for readability.

6. Arithmetic operators

  • + addition
  • - subtraction
  • * multiplication
  • / division
  • % remainder after division
  • ** exponentiation (power)
10 + 3; // 13
10 - 3; // 7
10 * 3; // 30
10 / 3; // 3.333...
10 % 3; // 1
2 ** 3; // 8

The remainder operator is useful for checking even numbers: number % 2 === 0.

7. Assignment operators

Assign a value or update a variable using its current value.

let total = 10; // = assign
total += 5;     // same as total = total + 5
total -= 2;     // same as total = total - 2
total *= 3;     // same as total = total * 3
total /= 2;     // same as total = total / 2

console.log(total); // 19.5

= assigns a value. It does not test equality; use === to compare values and types.

8. Comparison operators

Comparison operators produce a Boolean result: true or false. 

5 == "5";   // true (converts types)
5 === "5";  // false (type differs)
5 != "6";   // true (converts types)
5 !== "5";  // true
5 > 3;      // true
5 < 3;      // false
5 >= 5;     // true
4 <= 3;     // false

Prefer === and !== in most code because they avoid unexpected type conversion.
