JAVASCRIPT BASICS

User Input and Output

Learn how JavaScript receives information, checks it, and shows a result.

What are input and output?

Input is information a program receives from a user. Output is information the program gives back, such as a message, a number, or a result on a webpage.

Remember: Values received through prompt() and HTML text inputs are strings by default. Convert them when you need to do numeric calculations.

1. console.log()

Prints a value in the browser's developer console. It is useful for testing and debugging. 

const student = "Sara";
console.log("Welcome!");
console.log(student);
console.log(5 + 3);

// Output in the console:
// Welcome!
// Sara
// 8

How to see it: Open the webpage, press F12 (or right-click and choose Inspect), then select Console.

This button writes a message to the browser console.

2. alert()

Shows a simple message in a browser dialog. The user must dismiss it to continue interacting with the page. 

alert("Welcome to JavaScript!");

Avoid showing too many alerts in a real website.

3. prompt()

Asks the user to enter text. It returns a string, or null if the user cancels. 

const name = prompt("What is your name?");

if (name !== null) {
  alert(`Hello, ${name}!`);
}

4. confirm()

Asks the user to confirm an action. It returns true for OK and false for Cancel. 

const wantsToContinue =
  confirm("Do you want to continue?");

console.log(wantsToContinue); // true or false

5. Read values from HTML inputs

Use document.querySelector() or getElementById() to find an input, then read its .value. 

const nameInput =
  document.querySelector("#studentName");

console.log(nameInput.value);

6. Convert strings to numbers

An HTML input's .value is text. Convert it using Number() for arithmetic. 

const inputValue = "25";
const age = Number(inputValue);

console.log(age + 5); // 30

Without conversion, "25" + 5 produces "255" because + can join strings.

The converted result will appear here.

7. Display results in HTML

Use textContent to place text inside an element, such as a paragraph or heading. 

const output = document.querySelector("#output");
output.textContent = "Hello from JavaScript!";

The JavaScript result will appear here.

8. Basic input validation

Validation checks that input is present and acceptable before using it. Trim text to catch blank spaces and check numbers with Number.isFinite(). 

const raw = ageInput.value.trim();
const age = Number(raw);

if (raw === "") {
  // No input provided
} else if (!Number.isFinite(age) || age < 0) {
  // Invalid age
} else {
  // Valid age
}

This is basic client-side validation for learning. Important data must also be validated on the server.
