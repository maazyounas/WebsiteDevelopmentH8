What Is a Function?

A function is a reusable block of code that performs a specific task whenever we call it.

Basic Syntax

function functionName() {
    // Write your code here
}

functionName(); // Call the function

Understand the Syntax

  • function — keyword used to declare a function.
  • functionName — the name we give the function.
  • () — parentheses that can contain parameters.
  • { } — the function body, containing the code to execute.
  • functionName() — calls or executes the function.

Example

function sayHello() {
    console.log("Hello Students!");
}

sayHello();

First, we declare the function. Then we call it. The message appears when the function executes.

Function Declaration

A function declaration defines a named function using the function keyword.

Syntax

function functionName(parameters) {
    // Statements
}

functionName(arguments);

Example

function welcome() {
    return "Welcome to JavaScript!";
}

console.log(welcome());

Remember

  • The function is defined using its name.
  • It can be called multiple times.
  • Function declarations can generally be called before their definition in the same scope.

03

Function Expression

A function expression creates a function and assigns it to a variable.

Syntax

const variableName = function(parameters) {
    // Statements
};

variableName(arguments);

Example

const greet = function() {
    return "Good morning!";
};

console.log(greet());

Important Difference

Notice the semicolon after the closing brace. The function expression is part of a variable assignment.

Unlike a function declaration, a function expression assigned to a const variable cannot be called before that variable is initialized.

Parameters and Arguments

Parameters are placeholders in a function definition. Arguments are the actual values supplied when calling it.

Syntax

function greet(name) {
    return "Hello " + name;
}

greet("Ali");

Understand the Example

  • name is the parameter.
  • "Ali" is the argument.
  • The function uses the supplied value to create a greeting.

Return Values

The return keyword sends a result back to the code that called the function and ends that function's current execution.

Syntax

function functionName(parameters) {
    return result;
}

const answer = functionName(arguments);

Example

function add(a, b) {
    return a + b;
}

const answer = add(10, 20);

console.log(answer); // 30

Default Parameters

A default parameter supplies a fallback value when an argument is omitted or passed as undefined.

Syntax

function greet(name = "Guest") {
    return "Welcome " + name;
}

greet();       // Welcome Guest
greet("Sara"); // Welcome Sara

Arrow Functions

An arrow function is a shorter way to write a function expression, using the => symbol.

Syntax

const functionName = (parameters) => {
    // Statements
};

functionName(arguments);

Short Syntax

const square = number => number * number;

console.log(square(5)); // 25

Explanation

  • const square stores the function in a variable.
  • number is the parameter.
  • => defines the arrow function.
  • number * number is returned automatically because it is a concise expression body.

Anonymous Functions

An anonymous function is a function expression without its own function name.

Syntax

const greet = function() {
    return "Hello!";
};

console.log(greet());

Anonymous Function in an Event

button.addEventListener("click", function() {
    console.log("Button clicked!");
});

In the second example, the anonymous function is passed directly to addEventListener. It runs when the button is clicked.

Callback Functions

A callback is a function passed as an argument to another function so that the receiving function can call it.

Syntax

function process(callback) {
    callback();
}

function sayHi() {
    console.log("Hi!");
}

process(sayHi);

Explanation

  • sayHi is passed without parentheses.
  • callback receives the function.
  • callback() executes the received function.

process(sayHi) passes the function itself. process(sayHi()) would call it immediately and pass its return value instead.

Global and Local Variables

Global Variable

A variable declared outside a function can be accessed within its surrounding scope. 

const school = "ABC School";

function showSchool() {
    return school;
}

console.log(showSchool());

Local Variable

A variable declared inside a function is accessible within that function, subject to its scope. 

function showStudent() {
    const student = "Ali";
    return student;
}

console.log(showStudent());

// console.log(student); // ReferenceError

Function Scope and Block Scope

Scope determines where a variable can be accessed. Variables declared with let and const follow block scope.

Example

function checkMarks() {
    let marks = 80;

    if (marks >= 50) {
        let result = "Pass";
        console.log(result);
    }

    console.log(marks);

    // console.log(result);
    // ReferenceError: result is block-scoped
}

checkMarks();

The variable marks is available throughout the function. The variable result is only available inside the if block.

Basic Function Hoisting

Hoisting describes how JavaScript processes declarations before executing the code.

Function Declaration Example

sayWelcome();

function sayWelcome() {
    console.log("Welcome!");
}

This works because function declarations can be called before their definition in the same scope.

Function Expression Difference

// This would cause an error:
sayHello();

const sayHello = function() {
    console.log("Hello!");
};

A function expression stored in a const variable cannot be called before initialization. Do not execute the error example.
