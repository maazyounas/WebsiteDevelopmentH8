7. Image Tag

The <img> tag is used to display images on a webpage. 

```
```

Important attributes:

  • src - Specifies the image location.
  • alt - Provides alternative text for the image.
  • width - Specifies the image width.
  • height - Specifies the image height.

The <img> tag does not require a closing tag.

10. Nested Lists

A list can contain another list inside it. This is called a nested list. 

```


    

```
<li>
    Frontend
    <ul>
        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
    </ul>
</li>
```
```

Example:

  • Frontend
    • HTML
    • CSS
    • JavaScript
  • Backend
    • Node.js
    • Python
    • PHP

24. Basic Table Tags

HTML provides several tags for creating tables.

  • <table> - Creates the table.
  • <tr> - Creates a table row.
  • <th> - Creates a table heading.
  • <td> - Creates a table data cell.
```



```
<tr>
    <th>Name</th>
    <th>Age</th>
</tr>

<tr>
    <td>Ali</td>
    <td>20</td>
</tr>
```
```

Example:

Name Age Course
Ali 20 Web Development
Ahmed 21 Computer Science
