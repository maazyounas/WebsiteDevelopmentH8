CSS Display Properties

In this practice, we will learn the difference between:

  • display: block;
  • display: inline;
  • display: inline-block;
  • display: none;

1. display: block;

Block elements start on a new line and take the full available width.

2. display: inline;

Inline elements stay on the same line and only take the space required by their content.

3. display: inline-block;

Inline-block elements stay on the same line but allow us to set width and height.

An element with display: none is completely removed from the page.
